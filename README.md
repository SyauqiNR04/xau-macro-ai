# XAUUSD Macro AI Agent

Proyek riset dan backtesting strategi trading XAUUSD menggunakan analisis teknikal dan data makroekonomi Amerika Serikat.

## Fitur
- Pengambilan data melalui MetaTrader 5.
- Data makroekonomi dari FRED dan BLS.
- Analisis point-in-time dan backtesting.
- Audit hasil dan evaluasi out-of-sample.

## Instalasi
Aktifkan virtual environment Python dan jalankan `python -m pip install -r requirements.txt`.

## Status
Proyek masih dalam tahap riset dan validasi. Strategi belum terbukti menghasilkan keuntungan secara konsisten dan belum ditujukan untuk trading live.

## Keamanan
Jangan mengunggah API key, kredensial broker, file .env, atau dataset privat.
